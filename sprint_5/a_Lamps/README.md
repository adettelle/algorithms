# A. Лампочки

Ограничение времени	1 секунда
Ограничение памяти	64 Mb
Ввод	            стандартный ввод или input.txt
Вывод	            стандартный вывод или output.txt


Имеется гирлянда в виде бинарного дерева, в узлах которого находятся лампочки. У каждой лампочки есть своя яркость. Уровень яркости лампочки соответствует числу, расположенному в узле дерева. Найдите самую яркую лампочку в гирлянде, то есть такую, у которой яркость наибольшая.

### Формат ввода

На вход подается корень дерева.

### Формат вывода

Функция должна вернуть максимальное значение яркости в узле дерева.
