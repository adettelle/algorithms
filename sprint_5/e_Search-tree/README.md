# E. Дерево поиска

Ограничение времени	1 секунда
Ограничение памяти	64 Mb
Ввод	            стандартный ввод или input.txt
Вывод	            стандартный вывод или output.txt


Напишите функцию, которая определяет, является ли заданное дерево деревом поиска. Значения в левом поддереве должны быть строго меньше, в правом - строго больше значения в узле.

// Пример дерева:
//        5(5)
//       /   \
//	   3(3)  8(4)
//	  /   \
//	1(1)  4(2)

### Формат ввода

На вход функции подается корень бинарного дерева.


### Формат вывода

Функция должна вернуть True, если дерево является деревом поиска, иначе - False.

### Пример 1
Ввод:
3
0 2 1 2
1 5 -1 -1
2 3 -1 -1

      2(0)
     /   \
  5(1)   3(2)

Вывод:  
False
